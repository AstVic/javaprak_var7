# Системные тесты этапа 3

Системные тесты находятся в `src/test/java/ru/javaprak/system/RecruitmentSystemIT.java` и написаны на JUnit 5 + Selenium WebDriver.

## Запуск

1. Собрать и запустить приложение вместе с системными тестами:
   ```bash
   mvn verify
   ```
   Во время фазы `pre-integration-test` Maven поднимает Jetty на
   `http://localhost:8080/javaprak7-1.0.0-SNAPSHOT`, а Failsafe запускает
   Selenium-тесты против этого адреса.

2. Если приложение развернуто отдельно в Tomcat, можно указать адрес вручную:
   ```bash
   mvn failsafe:integration-test failsafe:verify -Dapp.baseUrl=http://localhost:8080/javaprak7
   ```

3. После успешного запуска в логах должно быть видно:
   ```text
   Tests run: 11, Failures: 0, Errors: 0, Skipped: 0
   BUILD SUCCESS
   ```

## Сценарии

| Метод теста | Use case | Проверяемый результат |
|---|---|---|
| `navigationPagesAreAvailable` | Навигация по приложению | Главная, размещение резюме, подбор вакансий и информационная страница открываются. |
| `resumeSearchReturnsResults` | Поиск резюме | По фильтрам возвращается список резюме с ожидаемой должностью. |
| `vacancySearchReturnsResults` | Поиск вакансий | По фильтрам возвращается список вакансий с ожидаемой должностью. |
| `invalidSalaryRangeShowsError` | Ошибка фильтра зарплаты | При `minSalary > maxSalary` отображается сообщение об ошибке. |
| `resumeCardShowsWorkHistory` | Просмотр карточки резюме | Отображается история работы соискателя. |
| `matchingVacanciesForResumeAreShown` | Подбор вакансий для резюме | Открывается страница подходящих вакансий. |
| `vacancyCardAllowsResponseAndRejectsDuplicate` | Отклик на вакансию | Повторный отклик для существующей пары резюме/вакансии отклоняется с сообщением. |
| `invalidResumeCreationShowsError` | Создание резюме с ошибкой | Отрицательная зарплата отклоняется с сообщением. |
| `resumeCreationSucceeds` | Успешное создание резюме | После отправки корректной формы создается новое резюме, выполняется переход на его карточку, отображаются сообщение об успехе и введенная зарплата. |
| `resumeUpdateSucceeds` | Успешное изменение резюме | Созданное тестом резюме редактируется, после сохранения отображаются сообщение об успехе и новое значение зарплаты. |
| `resumeDeletionSucceeds` | Успешное удаление резюме | Созданное тестом резюме удаляется, выполняется переход к списку резюме, карточка удаленного объекта больше не доступна из списка. |

Итого описано 11 системных тестов, что соответствует 11 методам с аннотацией
`@Test` в `RecruitmentSystemIT.java`.
