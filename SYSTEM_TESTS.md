# Системные тесты этапа 3

Системные тесты находятся в `src/test/java/ru/javaprak/system/RecruitmentSystemIT.java` и написаны на JUnit 5 + Selenium WebDriver.

## Запуск

1. Собрать WAR:
   ```bash
   mvn clean package -DskipTests
   ```
2. Развернуть `target/javaprak7-1.0.0-SNAPSHOT.war` в Tomcat 10+.
3. Подготовить PostgreSQL:
   ```bash
   mvn initialize generate-resources
   ```
4. Запустить системные тесты:
   ```bash
   mvn failsafe:integration-test failsafe:verify -Dapp.baseUrl=http://localhost:8080/javaprak7
   ```

## Сценарии

| Use case | Проверяемый результат |
|---|---|
| Навигация по приложению | Главная, размещение резюме, подбор вакансий и информационная страница открываются. |
| Поиск резюме | По фильтрам возвращается список резюме с ожидаемой должностью. |
| Поиск вакансий | По фильтрам возвращается список вакансий с ожидаемой должностью. |
| Ошибка фильтра зарплаты | При `minSalary > maxSalary` отображается сообщение об ошибке. |
| Просмотр карточки резюме | Отображается история работы соискателя. |
| Подбор вакансий для резюме | Открывается страница подходящих вакансий. |
| Отклик на вакансию | Повторный отклик для существующей пары резюме/вакансии отклоняется с сообщением. |
| Создание резюме с ошибкой | Отрицательная зарплата отклоняется с сообщением. |

В каждом тесте есть проверки через `assertTrue(...)`.
